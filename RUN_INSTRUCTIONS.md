# How to Run This Android Project

## 1) Download or clone the project

```bash
git clone https://github.com/zorvexglobalexim/rohit-assignment.git
cd rohit-assignment
```

## 2) Open in Android Studio

- Open Android Studio.
- Click on Open.
- Select the cloned folder `rohit-assignment`.
- Wait for Gradle sync to finish.

## 3) Install required tools

Make sure these are installed:

- Android Studio
- JDK 17
- Android SDK
- Android Emulator or a physical Android device

## 4) Run the app

- Select a device/emulator.
- Click the Run button (green play icon).
- The app will build and install.

## 5) If Gradle sync fails

Try these checks:

```bash
./gradlew clean
./gradlew assembleDebug
```

If Android Studio asks for SDK path, set it to your installed Android SDK location.

## 6) Notes

- This project is a local Android app and does not require any backend.
- The app uses on-device ML/face detection and TensorFlow Lite model files bundled in the project.
- Do not delete the `app/src/main/assets` files or model assets.

## 7) Recommended setup

For easiest setup on a desktop:

- Use Android Studio latest stable version
- Use an emulator with API 34 or higher
- Use JDK 17

## 8) Important

If you are sharing this project with someone else, keep the full project folder intact. Do not remove:

- `app/`
- `gradle/`
- `gradlew` and `gradlew.bat`
- `settings.gradle.kts`
- `build.gradle.kts`
- `local.properties` if generated by Android Studio
